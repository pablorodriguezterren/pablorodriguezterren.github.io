# PabloRodriguezTerren.github.io
https://pablorodriguezterren.github.io/

Esta calculadora web está desarrollada con HTML, CSS y JavaScript.
Las funcionalidades que ofrece son: 

- Operaciones unarias: Cuadrado, cubo, módulo, factorial y raíz cuadrada.

- Operaciones binarias: Sumas, multiplicaciones y potencias.

- Operaciones CSV: Suma, media, ordenar, invertir y eliminar último valor.

- Información dinámica: Un recuadro inferior actualiza y detalla cada operación realizada.

- Gestión de errores: Alertas para campos vacíos, raíces negativas y listas vacías.
